# 🏠 Sistema de Estoque Caseiro

Um sistema de controle de estoque doméstico desenvolvido para auxiliar no gerenciamento de alimentos e produtos da casa.

Este projeto está sendo desenvolvido como parte da minha jornada de aprendizado em Desenvolvimento de Software, evoluindo de uma aplicação de terminal para uma API REST profissional.

---

# 🎯 Objetivo

O objetivo do projeto é resolver um problema real: controlar os produtos disponíveis em casa, acompanhar o consumo e identificar automaticamente os itens que precisam ser comprados.

Além disso, o projeto serve como laboratório para estudo de tecnologias utilizadas no mercado de desenvolvimento de software.

---

# 🏗 Arquitetura

O projeto utiliza arquitetura em camadas para separar responsabilidades.

```
Cliente

↓

Routes

↓

Controllers

↓

Services

↓

Banco de Dados (em desenvolvimento)
```

Cada camada possui uma responsabilidade específica, tornando o sistema mais organizado, escalável e fácil de manter.
